# Dopamine Install Helper (Unofficial)

An unofficial, community-made guide website that helps users check device/iOS
compatibility and follow installation steps for the Dopamine jailbreak.

> The official repository is: https://github.com/opa334/Dopamine

## What this project is

- A static web page (`index.html`) with a compatibility checker, a step-by-step
  guide and a troubleshooting section.
- Available in English and Russian.

## What this project is NOT

- It does **not host, redistribute or modify** Dopamine or any IPA file.
  The download link is taken directly from the official GitHub release
  (with a fallback link to the same official source).
- It does **not** contain exploits, source code of the jailbreak, or any
  circumvention of copy protection.
- It is **not** an official website or an official repository.

## Compatibility data

Compatibility info is based on public information and may be incomplete or
outdated. Always check the official repository for current details.
